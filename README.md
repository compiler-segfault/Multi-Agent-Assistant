# 智能体集群助手

## 项目介绍

智能体集群助手是一个基于多智能体协作的AI系统，旨在为用户提供专业、个性化的学习成长支持。系统由多个专业智能体组成，通过灵活的协作机制，为用户解决学习、竞赛、科研和职业规划等方面的问题。

## 核心功能

### 1. 用户可控的智能体协作
- **主动参与调度**：用户可以直接指定调用某个智能体，如"让规划智能体回答"
- **智能推荐转接**：当智能体认为需要其他专业帮助时，会主动推荐转接
- **专家团队体验**：让用户感觉是在与一个专家团队对话，而非单个AI
- **提升交互体验**：增加用户参与感和交互灵活性

### 2. 模型映射机制
- **专业化分工**：为不同类型的智能体分配最适合的底层模型
- **模型优化**：
  - 日常问答智能体：使用 `deepseek-chat` 通用模型
  - 分析智能体：使用 `deepseek-r1-0528` 深度推理模型
  - 规划智能体：使用 `deepseek-coder` 逻辑生成模型
  - 执行智能体：使用 `deepseek-vl` 多模态处理模型
  - 评估智能体：使用 `deepseek-r1-0528` 批判性思维模型

### 3. 垂直聚焦场景
- **学习路线规划**：为用户制定个性化的学习计划
- **竞赛备战**：提供竞赛相关的指导和资源
- **科研入门导航**：帮助用户了解科研流程和方法
- **职业规划**：提供职业发展建议和路径规划

### 4. 透明化流程
- **工作过程展示**：将智能体集群的工作过程展示给用户
- **状态提示**：界面上会显示智能体的工作状态，如"规划智能体正在分析..."
- **增强信任**：通过透明化流程增加用户对系统的信任

### 5. 轻量级实现
- **单API+提示词+并行调用**：以极低成本复现集群核心思想
- **模块化设计**：便于后续扩展和模型升级
- **资源优化**：在成本和效果之间取得平衡

## 技术架构

### 前端技术栈
- **React 19.2.0**：构建用户界面
- **Framer Motion**：实现流畅的动画效果
- **React Markdown**：支持Markdown格式的内容渲染
- **Tailwind CSS**：响应式样式设计

### 后端技术
- **DeepSeek API**：提供底层模型支持
- **模型映射机制**：为不同智能体分配适合的模型
- **流式响应**：实现实时的对话体验

## 工作流程

1. **用户提问**：用户向系统提出问题
2. **智能体选择**：
   - 默认调用日常问答智能体
   - 用户可直接指定智能体
   - 智能体可推荐转接其他智能体
3. **模型调用**：根据智能体类型调用对应的底层模型
4. **响应生成**：智能体生成专业、结构化的回答
5. **结果评估**：评估智能体的回答质量
6. **流程透明**：向用户展示整个工作过程
