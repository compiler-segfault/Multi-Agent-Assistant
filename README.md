# 智能体集群助手

这是一个基于 React + Vite 构建的智能体集群助手展示网页项目，用于展示由多个智能体组成的集群系统如何协同工作来解决问题。

## 项目介绍

本项目展示了一个由多种专业智能体组成的集群系统，包括日常问答、分析、规划、执行、评估等智能体。这些智能体通过协同合作，为用户提供全面的智能服务。

## 核心功能

### 🤖 智能体集群系统
- **日常问答智能体** - 处理用户的日常问题
- **分析智能体** - 深入分析复杂问题
- **规划智能体** - 制定详细的行动计划
- **执行智能体** - 执行具体的任务
- **评估智能体** - 评估任务执行效果

### 💬 交互式聊天窗口
- **多行输入支持** - 输入框支持多行文本输入
- **自动高度调整** - 输入框从1行自动调整到最多10行
- **滚动条控制** - 超过10行时显示滚动条
- **AI 回复动画** - 模拟AI思考和打字的动画效果
- **聊天记录保存** - 关闭窗口后聊天记录不会丢失
- **智能输入禁用** - AI 讲话时自动禁用输入功能
- **内部滚动控制** - 聊天窗口打开时只允许内部滚动

### 🎨 现代前端设计
- **科技感界面** - 渐变背景和卡片式设计
- **响应式布局** - 支持桌面端、平板端、移动端
- **流畅动画效果** - 丰富的交互动画
- **数据可视化** - 工作原理和性能对比图表

## 页面内容

1. **导航栏** - 固定顶部导航，支持移动端响应式设计
2. **Hero 区域** - 全屏渐变背景，点阵动画效果
3. **灵感来源** - 智能体集群技术的灵感来源介绍
4. **设计背景与意义** - AI 智能体发展现状和集群技术的意义
5. **需求分析** - 智能体集群系统的核心需求
6. **核心技术** - 技术栈关系图和详细技术说明
7. **创新点** - 智能体集群的核心创新点
8. **未来创新方向** - 潜在的技术发展方向
9. **方案设计图** - 智能体集群架构示意图
10. **工作原理与验证** - 工作流程和性能对比图表
11. **页脚** - 项目信息、参考资料、联系方式

## 技术栈

- **前端框架**: React 18 + Vite
- **样式方案**: Tailwind CSS
- **动画库**: Framer Motion
- **图表库**: Chart.js + react-chartjs-2
- **图标库**: Font Awesome
- **字体**: Inter
- **Markdown 渲染**: react-markdown + remark-gfm

## 智能体工作流程

1. **用户输入** - 用户在聊天窗口中输入问题
2. **任务分配** - 系统根据问题类型分配给合适的智能体
3. **智能体协作** - 相关智能体协同工作解决问题
4. **结果整合** - 系统整合智能体的输出，形成最终答案
5. **响应反馈** - 向用户展示答案，支持Markdown格式

## 核心技术亮点

- **智能体通信协议** - 确保智能体之间快速、可靠地交换信息
- **智能任务调度算法** - 根据任务特性和智能体能力实现最优分配
- **灵活工作流程管理** - 支持不同智能体之间的动态切换
- **跨模态信息融合** - 支持处理不同类型的信息
- **资源分配优化** - 动态调整计算资源，提高系统性能
